## 🚀 About The Launcher

This is a heavily modified version of the **Plooshiware** launcher, rewritten in **WPF** for a modern and smooth user experience. It connects to the **kxprv** backend system (Arena, Double Shop, MongoDB).

* **WPF Interface**: Smooth animations and modern UI.
* **Season Support**: Compatible with almost every Fortnite version.
* **Backend Ready**: Pre-configured for kxprv's Arena & Double Shop system.
* **Database**: Syncs with MongoDB for player stats and inventory.



## ⚙️ How to use

### 1. Requirements
* **[.NET Desktop Runtime](https://dotnet.microsoft.com/download)** (Required to run the .exe).
* **Fortnite Game Files** (The versions you want to launch).

### 2. Launching the game
1. Download the latest release from the `Releases` tab.
2. Open the launcher.
3. Set your Game Path in the settings.
4. Click **Launch** and enjoy!

> **Note:** Version 17.50 is currently NOT supported.
